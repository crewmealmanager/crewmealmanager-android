# Crew Meal Manager – Android app

The Android app for https://crewmealmanager.github.io. It opens the website full screen (Trusted Web Activity), so every website update shows in the app straight away.

**Download the latest APK:** https://github.com/crewmealmanager/crewmealmanager-android/releases/latest/download/CrewMealManager.apk

To build a new version: Actions → Build Android app → Run workflow.
